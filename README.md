# StudySync

**Desktop 3.0.0-rc.3 — release candidate, based on develop-2.3.**

JavaFX windows, buttons, SQLite persistence, smart study planning, courses,
assignments, study history, workload, calendar, weighted grades and charts,
search, in-app deadline reminders, backups, database import, and CSV reports.

```sh
mvn clean verify
mvn javafx:run
```

Packaged desktop:

```sh
java -jar target/studysync-3.0.0-rc.3-all.jar
```

See [desktop guide](docs/DESKTOP-V3.md) for data locations, CLI compatibility,
Windows packaging, migration, milestone scope, and final acceptance checks.

This is a release candidate. Native Windows launch and final user acceptance
remain required before a stable v3.0 release.
